# HelpeRP 2.2.0 - Changelog

## 🚀 Новые возможности

### Автоматическая установка зависимостей
- При первом запуске exe файла приложение автоматически проверяет и устанавливает все необходимые Python пакеты
- Пользователю больше не нужно вручную устанавливать requirements.txt
- Опциональные пакеты устанавливаются автоматически (chromadb, langchain, requests)
- Bootstrap показывает прогресс установки в консоли

### Улучшенная поддержка Discord RPC
- ✨ Исправлено подключение с валидным Client ID
- 🔄 Discord presence теперь обновляется каждые 15 секунд (всегда видимый)
- 🛡️ Добавлена обработка ошибок - приложение не зависает если Discord недоступен
- ⏱️ Добавлен timeout на подключение (5-6 секунд максимум)
- Discord RPC инициализируется в отдельном потоке (не блокирует запуск)

### Расширенная поддержка templates v2.0
- 📖 Полная поддержка новых полей: variations, success_outcome, fail_outcome, advice
- 🎨 Красивое отображение всех элементов в GUI
- 📋 Структурированный вывод при копировании в буфер обмена

## 🔧 Улучшения

- Лучшая обработка ошибок при загрузке файлов данных
- Улучшен процесс инициализации приложения
- Более информативные логи при запуске
- Discord RPC работает стабильно даже при плохом соединении

## 🐛 Исправления

- Исправлена ошибка "Client ID is Invalid" для Discord RPC
- Приложение больше не зависает на этапе инициализации
- Исправлена проблема с неправильным форматированием template в GUI
- Лучшая обработка исключений при инициализации модулей

## 📦 Технические изменения

- Добавлен новый модуль `core/bootstrap.py` для инициализации зависимостей
- Обновлен `run.py` для вызова bootstrap на старте
- Обновлена версия в `core/version.py` до 2.2.0
- Улучшена обработка ошибок в `core/discord_presence.py`
- Обновлена документация в `docs/install.md`

## 🔐 Совместимость

- ✅ Windows 10/11 64-bit
- ✅ Python 3.10+
- ✅ Работает как из exe, так и из исходников
- ✅ Обратно совместимо с версией 2.0.1

## 📝 Заметки для пользователей

- При первом запуске exe может потребоваться интернет соединение для загрузки пакетов
- Процесс инициализации зависимостей отображается в консоли
- Если какие-то пакеты не установились, приложение все равно запустится (но может работать нестабильно)
- Discord RPC не является обязательным для работы приложения
