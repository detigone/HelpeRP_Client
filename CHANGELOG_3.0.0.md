# HelpeRP 3.0.0 — Итоговое обновление

**Дата:** 2026-08-15
**Версия:** 3.0.0
**Тип:** Major (итоговый финальный релиз)

---

## 🚀 Новые возможности

### Расширенная база данных фракций
- 📚 **Новые разделы в энциклопедии RP-терминов** — сформирована полная база знаний для всех фракций:
  - **Следственный комитет** (`data/sk.json`) — 14 регламентов: УД, экспертизы, осмотр, вещдоки, допрос
  - **Росгвардия** (`data/rosgvardia.json`) — 12 регламентов: ОМОН, охрана, оцепление, КТО
  - **СМИ** (`data/smi.json`) — 14 регламентов: ПРО, эфир, реклама, журналистика
  - **СМП** (`data/smp.json`) — 26 клинических протоколов: СЛР, ИВЛ, травмы, реанимация
- ⚖️ **МВД, ФСБ, Прокуратура, ФСИН, МЧС, Армия, Крайм, Законодательство РФ** — подробные редакции с терминами, уставами и статьями
- 🏷️ Поддержка «частых» записей (`is_frequent`) для быстрого доступа к топ-материалам

### Шаблоны отыгровок v2.0 (полная редакция)
- 🎬 **723 записи** шаблонов ролевых сценариев с полными линиями `/me`, `/do`, `/try`
- 🎭 Поддержка новых полей: `variations`, `success_outcome`, `fail_outcome`, `advice`
- 🔄 Вариации сценария в зависимости от ситуации (ночь, отказ водителя, побег и т.д.)
- 📋 Структурированный вывод при копировании в буфер обмена

### Итоговая система иконок
- 🎨 Заменены крупные PNG на лёгкие сжатые иконки для быстрого запуска и низкого потребления памяти
- 🖼️ Полный набор иконок для всех фракций и категорий через `core/icons.py` и `gui/icons.py`
- 📦 Автогенерация иконок из шрифта через `tools/generate_icons.py`
- 🌐 Поддержка загрузки иконок с Tabler Icons через `tools/download_tabler_icons.py`

## 🔧 Улучшения

- **Единый кэширующий загрузчик JSON** (`core/json_loader.py`) — убран дублирующий код кэша в measures и templates
- **Перепривязка глобальных хоткеев** (`core/hotkey_manager.py`) — исправлена утечка биндингов через `remove_hotkey(handle)` вместо строки
- **Улучшенный ранжированный поиск** (`core/search.py`, `core/rag_search.py`) — более точная выдача по фракциям и терминам
- **Расширенный справочник мер и наказаний** (`core/measures.py`) — уровни розыска 1–6 с разбором формулировок
- **Автоустановка зависимостей** (`core/bootstrap.py`) — при первом запуске exe проверяются и ставятся пакеты
- **Стабильный Discord RPC** — обновление каждые 15 сек, обработка ошибок, таймаут подключения, отдельный поток

## 🛡️ Безопасность (коммерческий релиз)

- 🔑 Лицензирование Ed25519 + публичный ключ для проверки подлинности
- 📝 Подписанные манифесты обновлений (защита от подмены пакета)
- 🗜️ Защита от Zip Slip при распаковке обновлений
- 🔐 Хранение API-ключей через DPAPI
- 🚫 Флаг `RELEASE_BUILD` для отключения dev-обхода в сборке

## 🐛 Исправления

- Исправлена утечка хоткеев при перепривязке из настроек
- Исправлена ошибка подключения Discord RPC (Invalid Client ID)
- Приложение больше не зависает при отсутствии Discord
- Корректная работа биндингов при каждом изменении настроек

## 📦 Технические изменения

- Версия поднята до **3.0.0** в `core/version.py`
- Обновлён `core/build_config.py` для release-сборки
- Добавлена единая система загрузки данных через `core/json_loader.py`
- Обновлён `settings.json.example` с новыми настройками хоткеев
- Добавлена документация: `docs/CODE_STYLE.md`, `docs/TABLER_ICONS_README.md`

## 🔐 Совместимость

- ✅ Windows 10/11 64-bit
- ✅ Python 3.10+ (из исходников)
- ✅ Работает как из exe, так и из исходников
- ✅ Полная обратная совместимость с 2.2.0

## 📝 Заметки для пользователей

- При первом запуске exe требуется интернет для установки пакетов
- Процесс инициализации зависимостей отображается в консоли
- Discord RPC не является обязательным для работы
- Все базы данных доступны офлайн после установки
