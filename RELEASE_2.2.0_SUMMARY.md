## 📋 Что было сделано

### 1. ✅ Версия обновлена до 2.2.0
- **Файл:** `core/version.py`
- **Изменение:** `VERSION = "2.2.0"`
- Автоматически подхватится всеми компонентами приложения

### 2. ✅ Создана система автоматической установки зависимостей
- **Новый файл:** `core/bootstrap.py`
- **Функция:** При запуске EXE файла автоматически:
  - Проверяет установку всех Python пакетов (customtkinter, keyboard, pypresence и т.д.)
  - Устанавливает недостающие пакеты через pip
  - Устанавливает опциональные пакеты (requests, chromadb, langchain)
  - Проверяет наличие файлов данных (data/*.json)
  - Показывает прогресс в консоли

**Преимущества:**
- ✓ Пользователю не нужно вручную устанавливать зависимости
- ✓ Работает прямо из EXE - достаточно интернета
- ✓ Graceful fallback если что-то не удалось установить
- ✓ Не блокирует запуск приложения при ошибках

### 3. ✅ Обновлен процесс инициализации приложения
- **Файл:** `run.py`
- **Изменение:** Bootstrap запускается в самом начале main()
- Bootstrap выполняется в главном потоке перед загрузкой GUI
- Все ошибки логируются но не критичны

### 4. ✅ Исправлены все проблемы с Discord RPC
- **Файл:** `core/discord_presence.py`
- **Исправления:**
  - Обновлен Client ID на валидный (1537723585798475826)
  - Добавлен timeout 5 сек на подключение
  - Подключение с обработкой в потоке (не блокирует)
  - Presence обновляется каждые 15 сек (всегда видимый)
  - Graceful error handling при недоступности Discord

- **Файл:** `settings.json`
- **Изменения:**

  - Правильный Client ID установлен

## 🎯 Как собрать и выпустить версию 2.2.0

### Быстрый старт (Windows PowerShell):

```powershell
# 1. Собрать EXE
python tools/build_exe.py

# 2. Тестировать локально
dist\HelpeRP_Release\HelpeRP.exe

# 3. Создать ZIP
python tools/release.py --version 2.2.0 --build

# 4. Получить SHA256
Get-FileHash dist\releases\HelpeRP_2.2.0.zip -Algorithm SHA256

# 5. Скопировать SHA256 и обновить updates/manifest.json

# 6. Создать GitHub Release с файлом HelpeRP_2.2.0.zip
```

**Полная инструкция:** смотрите `RELEASE_2.2.0_INSTRUCTIONS.md`
