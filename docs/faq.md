# FAQ — HelpeRP

## Лицензия и ключ

**Где взять ключ?**  
После покупки на сайте продавца. Формат: `HELPE-XXXX-XXXX-XXXXXXXX`.

**Ключ не подходит к ПК?**  
Возможно, ключ с привязкой к машине. Отправьте ID ПК из окна активации продавцу.

**Можно на двух ПК?**  
Один ключ = одна лицензия. Для второго ПК нужен второй ключ.

## ИИ

**ИИ не работает**  
Проверьте провайдера, API-ключ, Base URL и баланс аккаунта. Кнопка «Проверить API» в настройках.

**Какие нейросети поддерживаются?**  
**Локально (бесплатно, на вашем ПК):** Ollama, LM Studio, LocalAI, KoboldCpp, llama.cpp.  
**Облако:** OpenAI, DeepSeek, Groq, OpenRouter и любой OpenAI-совместимый API.

**Как запустить локально?**  
Настройки → ИИ → «Ollama (локально)» → установите Ollama → `ollama pull llama3.2` → кнопка ↻ → Проверить API.

**Отыгровка уходит сразу в чат**  
Отключите «Отправлять без предпросмотра» в настройках.

## База знаний

**Мало результатов**  
«Все базы» объединяет фракции. Уточните запрос или выберите конкретную фракцию.

**Контент не официальный закон**  
Справочник для RP-серверов, не юридическая консультация.

## Технические

**Окно не поверх игры**  
Включён режим topmost. Некоторые игры в fullscreen перекрывают overlay — используйте borderless/windowed.

**Хоткеи не работают**  
Запустите от имени администратора (для глобальных hotkeys библиотека `keyboard`).

**Как обновиться?**  
См. [updates.md](updates.md) — уведомление при запуске или «Проверить обновления» в настройках.
