# HelpeRP — документация

**HelpeRP** — десктопный оверлей для RP-игроков с локальной базой знаний, шаблонами, поиском по законам и поддержкой ИИ-отыгровок.

## Быстрый старт

1. Запустите `HelpeRP.exe` или выполните `py run.py`
2. Активируйте лицензионный ключ, если это требуется
3. Выберите интересующую фракцию в сайдбаре
4. Начните поиск через **Ctrl+F**
