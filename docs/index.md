# HelpeRP — документация (пробная версия)

## Быстрый старт

1. Запустите `HelpeRP.exe` или `py run.py`
2. Активируйте лицензионный ключ
3. Выберите фракцию в сайдбаре
4. Ищите записи через **Ctrl+F**
