# Установка HelpeRP

## Требования

- Windows 10/11 (64-разрядная версия)
- Интернет — для ИИ, онлайн-поиска и проверки обновлений
- API-ключ для провайдера ИИ — опционально, если вы используете облачный сервис

## Установка из exe

1. Распакуйте архив `HelpeRP_Release.zip`
2. Запустите `HelpeRP.exe`
3. Примите EULA и введите лицензионный ключ
4. Рядом с exe будет создан файл `settings.json`

## Установка из исходников

```bash
pip install -r requirements.txt
py run.py
```

Для разработки создайте файл `.helperp_dev` в корне проекта — активация не потребуется.

## Первоначальная настройка

1. **Настройки → ИИ** — API-ключ и Base URL
2. **Персонаж** — данные для промпта
3. **Игра** — клавиша чата (обычно `t`)
4. **Хоткеи** — при необходимости переназначьте

## Файлы рядом с программой

| Файл | Назначение |
|------|------------|
| `settings.json` | Все настройки пользователя |
| `HelpeRP.exe` | Основное приложение |

Не удаляйте встроенные папки `data` и `assets` — они упакованы в exe.

## Антивирус

PyInstaller-исполняемый файл иногда даёт ложные срабатывания. Добавьте папку с приложением в исключения антивируса или используйте исходный код напрямую.
