# Установка HelpeRP

## Требования

- Windows 10/11 (64-bit)
- Интернет — для ИИ, онлайн-поиска и проверки обновлений
- API-ключ OpenAI — опционально, для ИИ-функций

## Установка из exe

1. Распакуйте `HelpeRP_Release.zip`
2. Запустите `HelpeRP.exe`
3. Примите EULA и введите лицензионный ключ
4. Рядом с exe создастся `settings.json`

## Установка из исходников

```bash
pip install -r requirements.txt
py run.py
```

Для разработки создайте файл `.helperp_dev` в корне — активация не потребуется.

## Первоначальная настройка

1. **Настройки → ИИ** — API-ключ и Base URL
2. **Персонаж** — данные для промпта
3. **Игра** — клавиша чата (обычно `t`)
4. **Хоткеи** — при необходимости переназначьте

## Файлы рядом с программой

| Файл | Назначение |
|------|------------|
| `settings.json` | Все настройки пользователя |
| `HelpeRP.exe` | Приложение |

Не удаляйте встроенные папки `data`, `assets` — они упакованы в exe.

## Антивирус

PyInstaller-exe иногда даёт ложные срабатывания. Добавьте папку в исключения или используйте исходники.
