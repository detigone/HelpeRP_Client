# Руководство пользователя HelpeRP

## Интерфейс и анимации

HelpeRP использует плавные переходы:

- **Запуск** — плавное появление окна
- **Разделы** — смена страниц с лёгким сдвигом
- **Списки** — записи появляются каскадом
- **Компактный режим** — плавное изменение размера окна
- **Toast** — уведомления выезжают снизу
- **Загрузка** — анимированные точки при поиске и ИИ

Отключить: **Настройки → Интерфейс → Плавные анимации**

## Тема оформления

В **Настройки → Интерфейс** можно настроить внешний вид:

- **Тема** — 7 пресетов: HelpeRP Purple, Полночь, Океан, Закат, Изумруд, Графит, Стандартная
- **Свой акцент** — hex-цвет (`#7c3aed`), переопределяет акцент выбранной темы
- **Акцент от фракции** — если включено, цвет кнопок и выделений берётся от выбранной фракции; если выключено — из темы

Изменения видны сразу в превью; для сохранения нажмите **Сохранить настройки**.

## Интерфейс

### Сайдбар (слева)

- **База знаний** — статьи, протоколы, словарь по фракциям
- **Меры** — что грозит за нарушение (УК, КоАП, уровни розыска)
- **Настройки** — ИИ, персонаж, хоткеи, лицензия
- **Недавние** — последние открытые записи
- **Фракции** — переключение базы данных

### Основная область

- **Список** — результаты поиска и фильтров
- **Детали** — полный текст записи
- **Копировать** — текст в буфер обмена
- **Отыграть ИИ** — генерация RP-команд (нужен API-ключ)

## Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| `Shift+\` | Компактный ↔ развёрнутый режим |
| `Ctrl+Shift+H` | Скрыть / показать окно |
| `Ctrl+F` | Фокус на поиск |
| `↑` / `↓` | Навигация по списку |
| `Esc` | Сброс поиска |

## Раздел «Шаблоны»

- Готовые `/me`, `/do`, `/try` — **без API-ключа и без ИИ**
- Фильтр по фракции: МВД, СК, СМП, МЧС…
- **Копировать** или **Отправить в чат** одним кликом

## RAG-поиск

- Включён по умолчанию (BM25 + ключевые слова)
- Находит записи по смыслу, не только по точному совпадению
- Отключить: **Настройки → Поиск → Умный RAG-поиск**

## Профили персонажей

- **Настройки → Профили** — создайте несколько персонажей
- Переключение — выпадающий список **в сайдбаре**
- Активный профиль используется в ИИ-отыгровках

## Раздел «Энциклопедия»

- **74+ терминов** — RP, право, медицина, силовые структуры, ДТП
- **Wikipedia / Викисловарь** — при пустом локальном поиске (онлайн)
- Просмотренные статьи **сохраняются в кэш** и появляются в разделе «Энциклопедия»

## Поиск

- Умный ранжированный поиск по названию, тексту, ключевым словам
- Фильтр **Частые** — только часто используемые записи
- Категории — для протоколов и словаря
- Если локально не найдено — попытка онлайн-поиска (DuckDuckGo)

## Раздел «Меры»

- Фильтры: Все / УК / КоАП / Частые
- Уровень розыска 1–6 (клик по чипу в легенде)
- Копирование меры или полной статьи

## ИИ-отыгровки

### Локально (без серверов и оплаты)

Рекомендуется, если не хотите покупать облачные API:

1. **Настройки → ИИ** → выберите локальный провайдер:
   - **Ollama** — проще всего (`ollama.com`, затем `ollama pull llama3.2`)
   - **LM Studio** — GUI, загрузка моделей одним кликом
   - **LocalAI**, **KoboldCpp**, **llama.cpp server** — для продвинутых
2. Нажмите **↻** рядом с моделью — подтянутся установленные модели
3. **Проверить API** → **Сохранить**

Ключ для локальных **не нужен**. Всё работает на вашем ПК, интернет не обязателен после загрузки модели.

### Облако (платные API)

1. Выберите провайдера (OpenAI, DeepSeek, Groq, OpenRouter…)
2. Вставьте API-ключ → **Проверить API** → **Сохранить**
3. Укажите персонажа → **Отыграть ИИ**

| Локально | Облако |
|----------|--------|
| Ollama, LM Studio | OpenAI, DeepSeek |
| LocalAI, KoboldCpp | Groq, OpenRouter |
| llama.cpp server | Mistral, Together |

## Компактный режим

Строка быстрого поиска поверх игры. Enter — развернуть с результатами.
