# Техническое задание и архитектура проекта HelpeRP

**HelpeRP** — это интеллектуальный ИИ-оверлей (экосистема) нового поколения для RolePlay игроков (GTA 5 RP, SAMP, CRMP). Программа функционирует как прозрачный слой поверх игры, заменяя устаревшие статичные биндеры «умным» ИИ-напарником.

---

## 1. Стек технологий (Всё на Python)

Проект реализуется полностью на языке **Python**, что обеспечивает монолитность архитектуры, скорость разработки и простоту интеграции ИИ-модулей.

*   **Интерфейс игрока (GUI / Overlay):** `CustomTkinter`
    *   *Почему:* Современный UI в темных тонах, поддержка прозрачности, стабильная работа поверх окон (режим «В окне без рамки»).
*   **Глобальные хоткеи:** `keyboard`
    *   *Почему:* Перехватывает нажатия клавиш (например, `Alt + Space`) в фоновом режиме, даже когда игра развернута.
*   **Автоматизация ввода в игровой чат:** `pydirectinput` + `pyautogui`
    *   *Почему:* Имитирует прямое нажатие клавиш на аппаратном уровне (DirectX), что позволяет обходить защиту от простых кликеров во многих играх (GTA 5, SAMP).
*   **Сервер и API (Backend):** `FastAPI` + `Uvicorn`
    *   *Почему:* Самый быстрый асинхронный фреймворк для обработки тысяч одновременных запросов от клиентов.
*   **База знаний и Поиск (RAG):** `ChromaDB` (или `Qdrant`) + `LangChain`
    *   *Почему:* Локальная векторная база данных. Позволяет мгновенно находить нужные статьи и памятки по смыслу вопроса, экономя деньги на API.
*   **Искусственный Интеллект (LLM):** `OpenAI API` / `GigaChat API` / `Llama-3` (Локально)
    *   *Почему:* Отвечает за динамическую генерацию отыговок под конкретные ситуации и симуляцию характера персонажей.

## 2. Структура модулей и папок проекта

```
HelpeRP_Project/
│
├── backend/                # Серверная логика (ИИ и База знаний)
│   ├── app/
│   │   ├── core/           # Промпты ИИ, конфигурация моделей
│   │   ├── database/       # Векторное хранилище (ChromaDB) с законами и уставами
│   │   ├── services/       # Специфичная логика фракций (МВД, МЧС, СМП, СМИ, Крайм)
│   │   └── main.py         # Эндпоинты FastAPI для обработки запросов клиента
│   └── requirements.txt    # Зависимости сервера
│
├── client/                 # ПК-Приложение игрока (Оверлей)
│   ├── assets/             # Иконки, шрифты, звуки
│   ├── core/
│   │   ├── config.py       # Настройки (хоткеи, выбранный сервер, профиль персонажа)
│   │   ├── hotkeys.py      # Эмуляция ввода в игру, открытие чата, анти-AHK задержки
│   │   └── ai_client.py    # Связь с бэкендом (отправка запросов)
│   ├── gui/
│   │   ├── main_window.py  # Скрываемое окно оверлея (строка ввода)
│   │   ├── faction_ui.py   # Модули оформления под разные фракции
│   │   └── settings.py     # Конструктор биндов и окно кастомизации персонажа
│   └── run.py              # Главный файл запуска клиента
│
└── data_memos/             # Исходные файлы памяток, законов и ПРО (.json / .txt)
```

## 3. Пошаговый план разработки

### Этап 1: Архитектура Клиента и Хоткеи (Текущий этап)
*   [ ] Разработка базового окна оверлея (`CustomTkinter`), скрывающегося по `Alt + Space`.
*   [ ] Создание модуля `hotkeys.py` для автоматического открытия чата (клавиша `t`), вставки текста от ИИ и отправки (`Enter`).
*   [ ] Интеграция рандомизатора задержек (Anti-AHK) для защиты игрока от банов со стороны администрации сервера.

### Этап 2: Наполнение Базы знаний и RAG-система
*   [ ] Сбор и структурирование информации для фракций в JSON-файлы (УК/КоАП для МВД, ПРО для СМИ, регламенты СЛР для СМП).
*   [ ] Написание скрипта для загрузки этих данных в векторную базу данных `ChromaDB`.
*   [ ] Тестирование интеллектуального поиска: по запросу "перелом" система должна мгновенно доставать медицинскую памятку.

### Этап 3: Интеграция ИИ и Промпт-Инжиниринг
*   [ ] Написание системных промптов, обучающих ИИ выдавать исключительно команды `/me`, `/do`, `/try`, `/todo`.
*   [ ] Создание гибридного биндера (ИИ-Оптимизатора), который превращает простую заготовку игрока в красивую, кинематографичную отыгровку.
*   [ ] Внедрение кастомизации личности: адаптация генерируемого текста под звание и характер персонажа (например, "грубый капитан" или "неопытный интерн").

### Этап 4: Развитие модулей фракций
*   [ ] **МВД/ФСБ:** Модуль автоматического подбора статьи УК по описанию преступления.
*   [ ] **СМИ:** ИИ-авторедактор объявлений по правилам ПРО.
*   [ ] **Мафии:** Интерактивный ИИ-помощник по похищениям и ограблениям.

### Этап 5: Релиз и Тестирование
*   [ ] Сборка клиента в единый `.exe` файл для удобной установки игроками.
*   [ ] Тестирование оверлея в популярных RP-проектах (GTA 5 RP, Majestic, Arizona) на совместимость с игровыми чатами.
