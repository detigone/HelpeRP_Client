С ПРИВЯЗКОЙ К ПК (покупатель присылает ID из окна активации)
------------------------------------------------------------
Формат: HELPE-XXXX-XXXX-MMMMMMMM-XXXXXXXX
Пример для машины разработки (код 82EB9111):
HELPE-3JQU-ZEMV-82EB9111-9B221DBA

Генерация новых ключей:
  py tools/generate_license_key.py              — 1 универсальный
  py tools/generate_license_key.py 10         — 10 универсальных
  py tools/generate_license_key.py --bound ABCD1234  — под ID покупателя

Активация в HelpeRP.exe:
  1. Запустить HelpeRP.exe
  2. Принять EULA
  3. Вставить ключ → «Активировать»
  4. settings.json создаётся рядом с exe

Для разработки без ключа: файл .helperp_dev рядом с exe (не включать в релиз).
